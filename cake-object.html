VISUAL OBJECT / ART DIRECTION / 2026

CAKEOBJECT

A Drawing Becomes Physical
从二维手绘语言出发，把倾斜、层叠、滴落与彩色符号转译成具有体积与重量感的虚构实体。

PROJECT TYPE
个人视觉研究 / 虚构实体
ROLE
概念发起 · 视觉方向选择 · 产品形象确认与审阅
OUTPUT
实体研究 · 场景视觉 · 网页呈现

01 / CONCEPT

熟悉的形态，轻微偏离现实。

CAKE OBJECT 是一次从手绘语言出发的虚构实体研究。倾斜的层叠结构、滴落的边界与彩色符号组成物体的视觉语汇。日光、舞台和近景提供三种观看距离，在可信的光影中呈现一个略微偏离日常的存在。

01层叠与偏移
三层体块保持不完全对齐，建立不稳定但可识别的轮廓。
02滴落与边界
边缘不是规则切面，而是保留手绘中流动、融化的感觉。
03符号与笔触
彩色短划与水滴符号像表面记号，而非装饰贴图。
04垂直构件
黄白螺旋杆与红色顶端建立明确的上升方向。
05材质设定
高光釉面保留陶瓷般反射，同时避免过度光滑的 3D 感。
06摄影设定
以真实摄影逻辑为基础，仅保留少量超现实偏移。

02 / OBJECT STUDY

日光中的体积

俯视研究用于检查轮廓、重心，以及层叠主体与垂直构件之间的关系。

03 / VISUAL CAMPAIGN

一个克制的舞台

酒红色舞台把物体从中性的形态研究带入更具情绪的视觉传播场景，同时保持已确认的产品形态不变。

04 / ITERATION

保留物体，修正方向。

已确认

三层倾斜体块、黄白螺旋杆、红色顶端与明亮釉面，是最终持续保留的产品身份。

弃用方向

早期曾出现叶片顶部与低饱和配色，但它削弱了原产品的辨识度，因此被舍弃，回到原有结构继续细化。

05 / PROJECT NOTE

一个虚构物体，一种可感知的存在。

个人职责：概念发起、视觉方向选择、产品形象确认与审阅。场景衍生、文字整理与网页编排由生成式工具辅助完成。本项目不主张实体陶瓷制作、3D 建模或真实产品摄影。
