01 / VISUAL OBJECT STUDY / 2026

CAKEOBJECT

形态、材质与场景研究。

02 / CONCEPT

项目概念

CAKE OBJECT 是一个个人视觉研究项目。我从一个层叠、倾斜的物体形态出发，围绕比例、颜色、表面符号和材质进行调整，并通过不同角度和场景测试它的视觉表现。

PROJECT
个人视觉研究 · 2026
ROLE
概念发起 · 方向选择 · 形态确认与审阅
OUTPUT
形态研究 · 材质设定 · 场景测试

03 / HAND-DRAWN FORM STUDY

形态手绘研究

基于最终确认形态进行的手绘结构研究，用于重新观察比例、层间关系与表面符号。

04 / FORM & COLOUR

形态与色彩

主体由三个轻微错位的体块组成。彩色滴落、短线和顶部构件形成主要识别元素。

↔
01 / STACKING

层间错位

保留三层轻微倾斜与错位，让每层边缘都能被看见。

02 / SURFACE

滴落与短线

彩釉集中在层边；短线散布在奶油白表面，留出空白。

03 / PROPORTION

顶部与底盘

保留黄白螺旋杆和红色顶部；低圆底盘略宽于主体。

05 / OBJECT STUDY

多角度观察

从正面与斜俯视角度，检查三层轮廓、顶部位置和底盘比例。

06 / MATERIAL & DETAIL

材质与细节

材质设定以奶油白主体和局部彩色亮釉为主。重点是保持边缘、厚度和接触阴影可信。

07 / SCENE TEST

场景测试

在确认物体形态后，我测试了白底与酒红背景两种呈现方式。白底用于观察结构，酒红场景用于测试更偏传播视觉的氛围。

08 / ITERATION

方向调整

早期版本改变了顶部结构并降低了色彩饱和度，但削弱了原有形态的辨识度，因此最终回到原结构，只调整材质、光线和呈现方式。

01 / DISCARDED

弃用方向

叶片顶部、低饱和配色。形态辨识度减弱。

02 / RETAINED

最终保留

三层错位结构、黄白螺旋杆、红色顶部与彩色亮釉。

早期版本图像未收录，以上以文字记录方向判断。

09 / PROJECT NOTE

项目说明

CREDIT

个人职责：概念发起、视觉方向选择、物体形态确认与审阅。

工具辅助：物体视觉化、场景衍生、新增手绘风格研究图、文字整理与网页编排使用了生成式工具。手绘风格研究图基于最终确认形态补充制作，不是早期手稿或实际手绘过程的记录。

项目为视觉研究，未进行实体陶瓷制作、3D 建模或实物摄影。
